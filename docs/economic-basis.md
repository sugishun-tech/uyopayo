# 診断モデルと経済学的根拠

この診断は、回答者を8つの経済思想軸で表現し、24種類の思想レンズの重心に最も近いものを返します。

## 8つの軸

- 市場調整: 国家調整 ←→ 市場調整
- ルール志向: 裁量政策 ←→ ルール政策
- 貨幣安定: 雇用・需要優先 ←→ 物価・貨幣安定
- 誘因・所有権: 分配・労働 ←→ 誘因・所有権
- 開放経済: 保護・産業政策 ←→ 自由貿易
- 分析スタイル: 歴史・制度・権力 ←→ 形式モデル
- 金融不安定性: 金融は補助線 ←→ 金融は不安定化要因
- 革新・成長: 安定・福祉 ←→ 革新・企業家

## 設計思想

この診断は、左右の罵倒ラベルを強めるためではなく、政策論の前提を分解するためのものです。各結果には、強み、盲点、建設的な使い方、違うタイプと話すコツ、自分への点検質問を入れています。

経済政策の評価では、意図だけでなく、誘因、情報制約、実装能力、時間差、政府失敗、貨幣の安定、分配効果を分けて考えます。特に、裁量政策への過信、政治的誘因の軽視、インフレ制約の軽視を避けるため、マネタリスト／シカゴ学派的な警戒心を安全装置として置いています。

## 注意

診断結果は近似です。思想は混ざります。近い別タイプも読んでください。
